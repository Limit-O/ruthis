# Z 轴技术总纲（磁贴纵深 / 图层管理）

状态：设计定稿，待实施。Z1 实施前如有变更，先改本文档。

## 1. 概念与总规则

**同层保持网格纪律，跨层获得堆叠自由。**

- 同一层内：磁贴网格互斥（对齐、秩序，Metro 骨架不变）；
- 跨层：允许重叠，按 Z 序决定遮挡与命中。

这条规则同时定义了未来的窗口世界：**同层 = 平铺（tiling），跨层 = 堆叠（stacking）**。
"分层堆叠式窗口管理"即此公式的直接应用。

两层抽象：

- **整数 `z`**：每枚磁贴一个序号（允许空洞，同 CSS z-index），渲染顺序与命中测试的唯一依据；
- **图层（Layer，Z2 起）**：一段 z 区间的磁贴集合，有名字、可见性、激活态，是批量管理
  的操作单元。用户操作图层，个别磁贴可单独微调 z。

## 2. 交互设计

### 2.1 滚轮（Z 调整的唯一日常入口，右键菜单不再增加排序项）

| 输入 | 作用 | 条件 |
|---|---|---|
| 悬停磁贴 + **Super+滚轮** | 该磁贴沿 Z 提升或下沉（每次一格） | 见 2.4 焦点限制 |
| **Super+Tab**（按住 Super 连按） | 图层翻转切换器（Win7 Flip 式，Z3）——全部图层级联展开，Tab 前进 / Shift+Tab 后退，松开落定 | 桌面持有焦点（同 2.4） |
| 属性面板 | "永久置顶"开关 | 始终可用 |

方向语义：**向上滚 = 拉近（提升），向下滚 = 推远（下沉）**——Windows Phone 切换器的纵深隐喻。
滚轮向上=向自己移动，与"翻页向上=更前"的直觉一致。

### 2.2 图层翻转切换器（Super+Tab，Win7 Flip 式，Z3）

- 触发：按住 Super → 所有图层按 Z 序**级联展开**（前景大而亮、后景小而淡，
  沿纵深排布——桌面层版本的 Win7 Flip）；
- 循环：连按 Tab 选区向观者推进一层，Shift+Tab 后退；**松开 Super → 选中层
  升至前台成为激活层**，其余退后；
- 取消：Esc 或点按空白 = 回到原层；
- 视觉：级联卡片复用磁贴的投影/降透明语言，动画 250–300ms；
- 前置：依赖 Z2 的图层实体；本节替代原"悬停滚轮图层巡航"方案（用户定稿）；
- 绑定：KDE 默认未占用 Meta+Tab，实现时需实测确认；若个别版本被占用，
  由用户在系统设置解绑或换备用键；
- 焦点限制：同 2.3（桌面须持有键盘焦点）。

### 2.3 Super+滚轮的选型依据与两个注意项

**为什么是 Super 而非 Shift**（2026-10 定）：

- 纯 Super+滚轮在 KDE 默认**无任何绑定**（KWin 自带的修饰键滚轮行为是
  Super+Alt+滚轮切虚拟桌面，不占用纯 Super 组合），冲突面为零；
- Super（拇指徽标键）符合人体工学：一只手不离打字区；
- Shift+滚轮在应用界内是"横向滚动"的既成语义，Super+滚轮零歧义；
- 已知注意项 ①：KWin 的 Zoom 无障碍特效若被启用会占用 Meta+滚轮缩放全屏
  （默认关闭），文档记录，不作规避；
- 已知注意项 ②：同 2.4，修饰键只在表面持有键盘焦点时可见。

### 2.4 焦点限制（必须知道的边界）

桌面是 layer-shell 表面，键盘交互为 OnDemand（不能 Exclusive，否则全系统打不了字）。
后果：**表面未持有键盘焦点时，合成器不上报修饰键状态**，Super+滚轮会检测不到 Super。

- 聚焦时机：用户点击桌面（任意磁贴或空白）后即持有焦点，直到点击其他应用；
- 实现：滚轮处理器以 `window.active` 为闸——非激活时忽略修饰键判断，避免
  "失焦前残留的修饰键状态"造成误判（陈旧状态比无状态更糟）；
- 主流程不受影响（操作磁贴前必然先点它）；
- v1 不做未聚焦提示；若实际体验受伤，再考虑提示或 KWin 侧方案。

### 2.5 永久置顶（pinned）

- 数据：磁贴 `pinned: true`；
- v1 行为：z 视为最高带（渲染与命中永远在最上，跨层巡航/重排不影响）；
- 完整形态：置顶磁贴迁入**覆盖面（overlay layer-shell 表面）**，浮在真实窗口之上——
  这是第一个要求双表面架构的功能，也是窗口磁贴化的铺路石；
- 视觉标识：置顶磁贴右上角常驻小徽章，避免"为什么盖不住"的困惑；
- 入口：属性面板开关（右键菜单不加项）。

## 3. 数据模型

```jsonc
// tiles.json（向后兼容：缺 z/pinned 视为 0/false，老配置零迁移）
{
  "tiles": [
    { "type": "clock", "cx": 0, "cy": 0, "cw": 3, "ch": 2,
      "z": 0, "pinned": false, "...": "既有字段不变" }
  ],
  "layers": []   // Z2 起：[{ "id": 1, "name": "主层", "visible": true }]
}
```

- `z`：整数，可负可空洞；渲染与命中按 z 升序；
- `pinned`：布尔，优先级高于一切 z；
- 同层互斥落到 `findFreeSpot`：只统计与候选磁贴 **z 相邻重叠带**内的占用
  （v1 简化为"z 相同才算占用"，跨层重叠合法）；
- 添加磁贴：落在当前最上层（或 Z2 的激活图层）。

## 4. 渲染与视觉

- **命中即渲染序**：QML 委托 `z: model.z`（Item 原生 z 属性），遮挡与输入自动跟随，
  无需重排 model；
- **pinned**：委托 z 取极大值 + 右上角徽章；
- **高度感**：z > 0 的磁贴加投影（`MultiEffect`，QtQuick.Effects；Intel HD 520 上
  少量投影无压力，禁止全屏模糊）；
- **巡航动画**（Z2）：层切换沿 Z 位移 + 缩放 + 透明度，250ms，禁止模糊类效果；
- **非激活图层降透明**（Z2）：默认开（常驻信息层"沉"在下面若隐若现，很 Metro）。

## 5. 实现要点与坑

1. **滚轮拦截顺序**：Super+滚轮的处理器必须位于内容之上，先判 Super（且
   `window.active`）并 `accept`，其余滚轮事件 `accepted = false` 放行（便签等
   可滚动内容的滚轮不能被抢）；
2. **焦点限制**：见 2.3，OnDemand 不可改 Exclusive；
3. **层内 findFreeSpot**：占用判定从"任意磁贴重叠"改为"同 z 带重叠"，注意
   pinned 磁贴仍占用其格子；
4. **MultiEffect**：`import QtQuick.Effects`，仅对 elevated 磁贴开启；
   每帧重算阴影的开销与投影数量成正比；
5. **z 空洞**：删除磁贴留下的空洞合法，不做压缩；新磁贴 z 取当前最大 +1；
6. **兼容性**：老 tiles.json 无 z/pinned 字段 → 默认值，零迁移。

## 6. 与窗口磁贴化的衔接（设计前置约束）

- 磁贴在 ruthis 表面内部比 Z；真实窗口在 KWin 堆叠里比 Z——**层号是全局语义轴，
  表面只是层的宿主**；
- 永久置顶 → 覆盖面（overlay surface）；窗口磁贴 → KWin 堆叠映射进同一 z 序；
  外壳画框与徽章，几何由桥指挥 KWin；
- 因此 ruthis 最终形态 = 双表面（背景面：壁纸+沉底组件；覆盖面：置顶组件+窗口边框），
  本总纲的数据模型（z/pinned/图层）不需要为此改动。
