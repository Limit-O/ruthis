# Z 轴技术总纲（磁贴纵深 / 图层管理）

状态：Z1+Z3 已落地（2026-10-04，见文末落地记录）；Z2 的显式图层实体暂以
z 值派生平面的简化形态实现。后续变更先改本文档。

## 1. 概念与总规则

**同层保持网格纪律，跨层获得堆叠自由。**

- 同一层内：磁贴网格互斥（对齐、秩序，Metro 骨架不变）；
- 跨层：允许重叠，按 Z 序决定遮挡与命中。

这条规则同时定义了未来的窗口世界：**同层 = 平铺（tiling），跨层 = 堆叠（stacking）**。
"分层堆叠式窗口管理"即此公式的直接应用。

两层抽象：

- **整数 `z`**：每枚磁贴一个序号（允许空洞，同 CSS z-index），渲染顺序与命中测试的唯一依据；
- **图层（Layer，Z2 起）**：一段 z 区间的磁贴集合，有名字、可见性、激活态，是批量管理
  的操作单元。用户操作图层，个别磁贴可单独微调 z。

## 2. 交互设计

### 2.1 滚轮（Z 调整的唯一日常入口，右键菜单不再增加排序项）

| 输入 | 作用 | 条件 |
|---|---|---|
| 悬停磁贴 + **Super+< / Super+>** | 该磁贴沿 Z 推远/拉近（按平面边界步进） | 见 2.4 焦点限制 |
| **Super+Tab**（按住 Super 连按） | 图层翻转切换器（Win7 Flip 式，Z3）——全部图层级联展开，Tab 前进 / Shift+Tab 后退，松开落定 | 桌面持有焦点（同 2.4） |
| 属性面板 / 右键菜单 | "永久置顶"开关 | 始终可用 |

方向语义：**向上滚 = 拉近（提升），向下滚 = 推远（下沉）**——Windows Phone 切换器的纵深隐喻。
滚轮向上=向自己移动，与"翻页向上=更前"的直觉一致。

### 2.2 图层翻转切换器（Super+Tab，Win7 Flip 式，Z3）

- 触发：按住 Super → 所有图层按 Z 序**级联展开**（前景大而亮、后景小而淡，
  沿纵深排布——桌面层版本的 Win7 Flip）；
- 循环：连按 Tab 选区向观者推进一层，Shift+Tab 后退；**松开 Super → 选中层
  升至前台成为激活层**，其余退后；
- 取消：Esc 或点按空白 = 回到原层；
- 视觉：级联卡片复用磁贴的投影/降透明语言，动画 250–300ms；
- 前置：依赖 Z2 的图层实体；本节替代原"悬停滚轮图层巡航"方案（用户定稿）；
- 绑定：KDE 默认未占用 Meta+Tab，实现时需实测确认；若个别版本被占用，
  由用户在系统设置解绑或换备用键；
- 焦点限制：同 2.3（桌面须持有键盘焦点）。

### 2.3 Super+滚轮的选型依据与两个注意项

**为什么是 Super 而非 Shift**（2026-10 定）：

- 纯 Super+滚轮在 KDE 默认**无任何绑定**（KWin 自带的修饰键滚轮行为是
  Super+Alt+滚轮切虚拟桌面，不占用纯 Super 组合），冲突面为零；
- Super（拇指徽标键）符合人体工学：一只手不离打字区；
- Shift+滚轮在应用界内是"横向滚动"的既成语义，Super+滚轮零歧义；
- 已知注意项 ①：KWin 的 Zoom 无障碍特效若被启用会占用 Meta+滚轮缩放全屏
  （默认关闭），文档记录，不作规避；
- 已知注意项 ②：同 2.4，修饰键只在表面持有键盘焦点时可见。

### 2.4 焦点限制（必须知道的边界）

桌面是 layer-shell 表面，键盘交互为 OnDemand（不能 Exclusive，否则全系统打不了字）。
后果：**表面未持有键盘焦点时，合成器不上报修饰键状态**，Super+滚轮会检测不到 Super。

- 聚焦时机：用户点击桌面（任意磁贴或空白）后即持有焦点，直到点击其他应用；
- 实现：滚轮处理器以 `window.active` 为闸——非激活时忽略修饰键判断，避免
  "失焦前残留的修饰键状态"造成误判（陈旧状态比无状态更糟）；
- 主流程不受影响（操作磁贴前必然先点它）；
- v1 不做未聚焦提示；若实际体验受伤，再考虑提示或 KWin 侧方案。

### 2.5 永久置顶（pinned）

- 数据：磁贴 `pinned: true`；
- 渲染：**LayerTop 覆盖面**（双表面架构已落地）——置顶磁贴由独立 layer-shell
  窗口承载，浮于一切真实窗口之上；主面（背景层）不再渲染它们；
- 输入：覆盖面键盘互操作 None（永不劫持打字），鼠标输入区 = 置顶磁贴矩形
  并集（QWindow::setMask），其余区域点击穿透到真实窗口；覆盖面禁拖拽
  （mask 不随拖动更新）；主面保存（tiles/settingsChanged）驱动覆盖面刷新；
- 视觉标识：无（覆盖面本身就是"置顶"语义，不加徽章）；
- 入口：右键菜单 / 属性面板开关。

## 3. 数据模型

```jsonc
// tiles.json（向后兼容：缺 z/pinned 视为 0/false，老配置零迁移）
{
  "tiles": [
    { "type": "clock", "cx": 0, "cy": 0, "cw": 3, "ch": 2,
      "z": 0, "pinned": false, "...": "既有字段不变" }
  ],
  "layers": []   // Z2 起：[{ "id": 1, "name": "主层", "visible": true }]
}
```

- `z`：整数，可负可空洞；渲染与命中按 z 升序；
- `pinned`：布尔，优先级高于一切 z；
- 同层互斥落到 `findFreeSpot`：只统计与候选磁贴 **z 相邻重叠带**内的占用
  （v1 简化为"z 相同才算占用"，跨层重叠合法）；
- 添加磁贴：落在当前最上层（或 Z2 的激活图层）。

## 4. 渲染与视觉

- **命中即渲染序**：QML 委托 `z: model.z`（Item 原生 z 属性），遮挡与输入自动跟随，
  无需重排 model；
- **渲染 z 归一**：常态委托 z 取 `(model.z||0) - planes[0]`（最低平面归零），
  否则负 z 的磁贴会画到壁纸（z=0 前序兄弟）之下；
- **pinned**：委托 z 取极大值 + 右上角徽章；不参与翻转（flipDepth 恒 0，
  级联期间保持锐利、恒在最上）；
- **高度感**：z > 0 或置顶的磁贴加投影（矩形伪影；多效果可换 `MultiEffect`，
  QtQuick.Effects；Intel HD 520 上少量投影无压力，禁止全屏模糊）；
- **透视纵深（真 3D 后退）**：翻转时每层整体后退——位置向消失点收敛 +
  均匀缩放（s = eye/(eye+z)）+ 绕自身竖直中轴 rotateY（随深度加大的
  `Matrix4x4` 透视矩阵，含透视除法产生近大远小），磁贴与层卡同一变换；
  远层叠轻模糊 + 压暗，选中层=交互层锐利全亮。**Qt 6.11 实测：QML 自定义
  ShaderEffect（含官方最简示例）静默不渲染**，自定义 qsb 着色器路线废弃
  勿再引入；
- **同层重叠**：合法（拖拽即成）。拖动中的磁贴渲染序抬到全部平面之上；
  最近拖动者（root.lastDragged）在本层置顶——"谁后拖谁在上"，不改数据 z；
- **层标识卡**：翻转时每层一张整体深灰玻璃卡 + 亮色描边（包住该层全部磁贴的
  包围盒；z 取"本层磁贴 z − 1"——垫在本层磁贴之下、更深内容之上），
  选中层描边更粗更亮；点层卡或点模糊磁贴即选中该层；
- **巡航动画**（完整形态）：层切换沿 Z 位移 + 缩放 + 透明度，250ms，
  禁止模糊类效果；
- **非激活图层降透明**（Z2）：默认开（常驻信息层"沉"在下面若隐若现，很 Metro）。

## 5. 实现要点与坑

1. **滚轮拦截顺序**：Super+滚轮的处理器必须位于内容之上，先判 Super（且
   `window.active`）并 `accept`，其余滚轮事件 `accepted = false` 放行（便签等
   可滚动内容的滚轮不能被抢）；
2. **焦点限制**：见 2.3，OnDemand 不可改 Exclusive；
3. **层内 findFreeSpot**：占用判定从"任意磁贴重叠"改为"同 z 带重叠"，注意
   pinned 磁贴仍占用其格子；
4. **MultiEffect**：`import QtQuick.Effects`，仅对 elevated 磁贴开启；
   每帧重算阴影的开销与投影数量成正比；
5. **z 空洞**：删除磁贴留下的空洞合法，不做压缩；新磁贴加入当前最上层平面
   （实测修正：原定"最大 +1"新开平面会让空平面上所有新磁贴叠在同一点，
   见 §8）；
6. **兼容性**：老 tiles.json 无 z/pinned 字段 → 默认值，零迁移。

## 6. 与窗口磁贴化的衔接（设计前置约束）

- 磁贴在 ruthis 表面内部比 Z；真实窗口在 KWin 堆叠里比 Z——**层号是全局语义轴，
  表面只是层的宿主**；
- 永久置顶 → 覆盖面（overlay surface）；窗口磁贴 → KWin 堆叠映射进同一 z 序；
  外壳画框与徽章，几何由桥指挥 KWin；
- 因此 ruthis 最终形态 = 双表面（背景面：壁纸+沉底组件；覆盖面：置顶组件+窗口边框），
  本总纲的数据模型（z/pinned/图层）不需要为此改动。

## 8. 落地记录（2026-10-04，Z1+Z3）

- **平面派生**：`planes` = 非 pinned 磁贴 z 值的去重升序数组（`zRevision` 计数器
  驱动重算；ListModel 的 get/setProperty 无变更通知，依赖计数器是必须的）。
  显式图层实体（命名/可见性/激活态/批量管理）随 Z2 暂缓；
- **翻转循环**：Super 按住时 Tab 事件带 Meta 修饰，`Shortcut("Tab")` 匹配不上、
  `Meta+Tab` 快捷键此时又已禁用——连按 Tab 必须由翻转覆盖层 `Keys.onPressed`
  按键名处理；进入翻转时 `forceActiveFocus()` 保证覆盖层持有焦点（松开 Super
  落定也依赖它）；
- **Super+滚轮**：以 `window.active` 为闸（见 2.4），步进按平面边界（升到上一
  平面 z / 降到下一平面 z，无相邻平面时 ±1，允许制造新平面与空洞）；
- **新磁贴落位**：加入当前最上层平面（`z = topZ()`，非"最大 z+1"新开平面，
  否则空平面会让所有新磁贴叠在同一点）；`findFreeSpot(w, h, targetZ)` 只统计
  targetZ 同带与 pinned 的占用，跨层重叠合法（§3）；
- **Super+滚轮步进与 landFlip** 使用"最大 z + 1"开新平面（升级选中层）；
- **纵深模糊**：MultiEffect 方案见 §4；模糊量 `min(1, 0.06 + 0.08 × flipDepth)`，
  blurMax 32，仅翻转期间对 depth>0 的磁贴启用；
- **调试**：`--open-flip` 启动即进入翻转模式并自截帧到 `/tmp/ruthis-window.png`
  （窗口被遮挡时外部截不到屏）；`--test-menu` 合成鼠标事件回归右键菜单链路；
  `--test-overlay` 窗口模式下创建覆盖面验证穿透；
- **键位变更（2026-10 用户定稿）**：层次微调由 Super+滚轮改为 Super+< / >；
  悬停目标经各磁贴 HoverHandler 汇聚到 `root.hoveredTile`；
- **同层互斥拖拽兜底**：拖动落点与本层/置顶磁贴重叠则弹回原格（添加侧
  findFreeSpot 同带判定早已生效）；
- **覆盖面落地**：desktopMode 下创建第二 layer-shell 窗口（LayerTop、键盘
  None），独立引擎加载同一 Main.qml（`OverlayMode` 上下文），后端单例跨引擎
  共享；`Store.save/saveSettings` 发信号驱动覆盖面重载；
  `Store.applyMask`（QWindow::setMask）把输入区限定在置顶磁贴并集内。
